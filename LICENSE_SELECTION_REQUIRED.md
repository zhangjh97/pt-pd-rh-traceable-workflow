# License selection required before public release

No license is granted by this draft package.

Before making the repository public, the authors and rights holder should approve licenses. A common arrangement is:

- source code written by the authors: MIT License;
- author-generated tabular data and structures: Creative Commons Attribution 4.0 International (CC BY 4.0);
- third-party software, model weights, pseudopotentials and database records: their original licenses.

Confirm employer, funding, patent, and co-author requirements before adding license files. Do not apply an author license to third-party resources that the authors do not own.
