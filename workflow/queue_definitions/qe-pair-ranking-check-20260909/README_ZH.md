# 两组同组成候选的k点排序复核

该包包含4项固定几何SCF，使用24 MPI ranks、4 pools、每进程1线程，可与12核三元加密检查并行。不要重复启动原24核主优化队列。

| 结构 | 原优化网格 | 本次网格 | 偏移 |
|---|---|---|---|
| Pt-Pd-01_Pd4Pt4 | 7x5x5 | 10x8x8 | 1 1 1 |
| Pt-Pd-15_Pd4Pt4 | 6x6x6 | 8x8x8 | 1 1 1 |
| Pd-Rh-14_Pd2Rh6 | 10x10x2 | 14x14x4 | 1 1 1 |
| Pd-Rh-06_PdRh3 | 10x6x6 | 14x8x8 | 1 1 1 |

网格由各自最终晶胞的含2pi倒格矢长度计算：每方向网格数为不小于 |b_i|/0.18 的最小偶数，即方向间距不超过0.18 Å^-1。采用统一偏移协议，不要求各方向间距完全相等。相较原计算，网格数和部分网格偏移共同变化，报告时应称“统一密网格协议下的排序复核”，不能将差异只归因于点数。

坐标直接来自已核验的原成功output.part01.log，未使用CIF重新定向，也未使用原scratch。晶胞和原子坐标保持不变。各输入与原日志SHA256和实际倒空间间距见provenance.json。

保持110/440 Ry、MV展宽0.02 Ry、相同统一PseudoDojo赝势、SCF阈值1e-8 Ry。四项顺序执行，各项单次时间上限6小时，最多自动续算一次；时间上限不是预计耗时。仅在正常时间限制退出且存在检查点时自动恢复，其他错误停止保留现场。

## 启动与查看

```bash
cd /mnt/d/qe-pair-ranking-check-20260909
python3 queue.py start
python3 queue.py status
```

只需服务器现有Python3、QE7.5和MPI，无额外Python依赖。启动前要求已有pw.x进程不多于12、可用内存至少24GiB、Linux数据盘可用空间至少15GiB。启动后后台运行，锁防止同包重复启动；已完成任务检查原始日志和退出码后跳过，未完成旧目录拒绝覆盖。

## 结束与分析


重点比较最终SCF总能量每原子的同组成差值：

- Pt-Pd：E(Pt-Pd-15)/8 - E(Pt-Pd-01)/8；原差值约+50.024 meV/原子。
- Pd-Rh：E(Pd-Rh-06)/4 - E(Pd-Rh-14)/8；原差值约+53.753 meV/原子。

差值为正表示各组后者原本更低能的结构仍更低能。同组成比较元素参考能相消，因此无需为了这两个差值新增元素参考计算。本任务不直接提供独立验证的绝对形成能，也不能把两网格之间的变化当作严格误差上界。

还需检查最终原子力和完整应力，必要时才决定短程优化。这4项不改变正在执行的三元代表结构加密任务。
