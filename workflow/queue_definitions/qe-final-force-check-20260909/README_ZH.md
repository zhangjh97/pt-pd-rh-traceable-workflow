# 今晚的4项力精度复核

## 目的

仅复核已完成密网格单点计算中有力精度警告的4个结构。保持各自的赝势、晶胞、原子坐标、k网格、110/440 Ry截断能、0.02 Ry展宽不变，将电子收敛阈值收紧至1e-10 Ry。不是重新做结构优化，也不自动增加其它任务。

12 MPI进程单独计算k_dense3_alloy；另外24 MPI进程依次计算Pd-Rh-06、Pt-Pd-01、Pd-Rh-14。两路同时运行，最多36 MPI进程，数值库线程数均为1。

## 启动

把整个文件夹放在服务器D盘，确认下面路径直接含queue.py。Ubuntu执行：

```bash
cd /mnt/d/qe-final-force-check-20260909
python3 -I queue.py start --hours 10
python3 -I queue.py status
```

需要原先两个队列全部结束，程序检测到任何pw.x进程会拒绝启动。启动后后台运行，断开远程连接不影响它；不要关闭WSL、重启、关机或让服务器休眠。

必须保留命令中的-I：它使用Python隔离模式，避免本文件queue.py遮蔽同名标准库模块。后台worker也用-I启动。旧包不必重新下载，可先执行export PYTHONSAFEPATH=1，再用原python3 queue.py命令；该环境变量会被旧版后台worker继承。新终端需重新设置环境变量，或在本修正版中统一使用-I。

10小时是从启动开始计算的计划预算，并非保证用满或严格停止时间。每段QE最长4小时，最多两段；后启动的任务会缩短时间以适应总预算。QE只在部分检查点检查max_seconds，可能超时一些。租期结束前预留至少一小时查看状态、导出和转移数据。不能保证四项均能在预算内完成。

## 安全与重用

原结果目录为~/qe-paper-runs/kdense3_check_20260909和pair_ranking_check_20260909。先核对最终日志哈希、退出码、输入和赝势，再将每个已收敛的.save目录复制到独立的新目录，读取已有电荷密度与波函数开始更严格的新SCF。

原结果与原检查点均不修改。新输出位于~/qe-paper-runs/final_force_check_20260909。需要至少40 GiB可用内存、足够容纳复制检查点再加20 GiB的空闲空间，以及原.save内的电荷密度、波函数、XML。缺失任一项则停止，不擅自从头重算。若看到STOP，回传完整提示。

同一计算未完成时禁止重复启动或覆盖。正常达到时间限制且保存成功的第一段可自动续算一次；其它失败保留现场，需检查后处理。不使用restart去修改一个已经结束任务的精度；第一段使用from_scratch + startingpot/startingwfc=file，第二段仅用于本次新任务的干净续算。

## 完成后

```bash
python3 -I queue.py status
python3 -I queue.py export
```

导出文件在服务器D盘，名字qe-final-force-results-时间.tar.gz。复制回本机项目的data/dft_runs。导出不包含大scratch，但服务器原目录中保留。允许导出未完成诊断结果，不能把导出成功当作计算成功。

DONE表示四项严格SCF完成；DONE_REVIEW_FORCES表示电子收敛完成但仍存在力修正警告。二者都不等于密网格下结构已完全优化，仍需比较能量、原子力和完整应力张量。若警告或残余应力仍值得关注，再决定是否做针对性短程晶胞优化。论文应区分基础网格优化与密网格固定几何验证。

本包不重算元素参考，因其最终SCF误差已经小于1e-10 Ry；不重跑整个主队列、不扩大整套k点扫描。包在本机通过模拟队列测试，不等于已在服务器或实际QE上执行。
