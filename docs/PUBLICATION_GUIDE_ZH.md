# 发布与使用说明

本仓库对应当前Pt-Pd-Rh论文。作者自有软件采用MIT，作者生成的数据采用CC BY 4.0。第三方材料见根目录THIRD_PARTY_NOTICES.md；赝势及归档内副本保留PseudoDojo的CC BY 4.0许可。

在仓库根目录运行 `python code/verify_release.py` 可核验现有记录，不会启动计算。原始脚本保留在code/original，部分路径需要适配本地环境。

## 公开与投稿

1. 提交并推送最新版文档、许可证及校验清单。
2. GitHub仓库Settings > General > Danger Zone > Change repository visibility，选择Public并确认。
3. 用未登录的浏览器窗口打开仓库，确认README、code和data可访问。
4. 回复编辑并提供地址，说明投稿系统锁定，请编辑记录数据声明或重新开放修改。
5. 第3步通过后才能使用AVAILABILITY_TEXT_DRAFT.md中的公开表述。

网址：https://github.com/zhangjh97/pt-pd-rh-traceable-workflow
